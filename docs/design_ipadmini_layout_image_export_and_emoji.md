# MindFlow Studio - iPad mini縦向きUI最適化・画像エクスポート・絵文字機能設計書

## 1. 目的と要件

1. **iPad mini 縦向き（幅744px〜768px）でのメニューバー崩れ防止**
   - 「マップ管理」等のテキストが縦書きのように1文字ずつ折れてメニューからはみ出る問題を解消。
   - 「マップ」と「管理」の2行レイアウト（アイコン＋2行ラベル）や `whitespace-nowrap` の適用により、タブレット縦向きでも美しく整然としたナビゲーションを実現。
2. **画像形式（PNG / SVG）でのエクスポート機能**
   - 作成したマインドマップ全体を高解像度PNG画像およびベクターSVG形式で保存・共有可能にする。
3. **ノード先頭への絵文字（Emoji）付与機能**
   - 直感的な絵文字ピッカーUIの提供。
   - 「直近で使った絵文字（Recent）」の自動記憶・最上部表示。
   - カテゴリ別（アイデア/タスク、感情/人、ビジネス、デザイン/ツール等）の絵文字一覧。
   - ワンタップでノード先頭への付与・差し替え・削除が可能。
4. **index.html への一本化**
   - メインソースを `index.html` に集約しつつ、既存URL互換のため `mindflow_studio.html` も完全同期を維持。

---

## 2. 詳細設計

### 2.1 ヘッダーのタブレット縦向き対応
- ボタン内のテキスト折り返し制御:
  - `whitespace-nowrap` を徹底し、文字が縦長に折れることを防止。
  - 「マップ管理」ボタンを「マップ」と「管理」の2行構成（`flex flex-col text-[10px] leading-tight`）またはスマートなコンパクト表示にし、iPad mini の画面幅でも左右の要素が重ならず余裕を持って収まるようにパディングとギャップを最適化。

### 2.2 画像エクスポートエンジン（PNG & SVG）
- **PNGエクスポート**:
  - 全ノードの表示座標（minX, minY, maxX, maxY）を算出し、十分なパディング（40px〜60px）を確保したオフスクリーン Canvas を構築。
  - デバイスピクセル比（Retina対応）を考慮した高解像度描画。
  - 背景、SVG接続線（三次ベジェ曲線、関連線）、ノード（背景色、枠線、絵文字、テキスト、チェックボックス、折りたたみ状態）を Canvas 上に忠実に再現。
  - `canvas.toBlob()` を経由してワンクリックで `.png` 保存。
- **SVGエクスポート**:
  - SVGレイヤーとノードDOM要素を完全なスタンドアロンSVGドキュメントとしてパッケージングし、`.svg` 保存。

### 2.3 絵文字ピッカーシステム
- **データ構造**:
  - 各ノードオブジェクトに `emoji?: string` を保持。
  - `renderNodes()` において、テキスト先頭に絵文字バッジを表示。
  - Markdownエクスポート時にも先頭に絵文字を反映。
- **UIコンポーネント (`#emojiPickerModal`)**:
  - 直近使用絵文字セクション（LocalStorageに最大12個保存）。
  - カテゴリタブ（💡アイデア・タスク、👤人・表情、💼ビジネス・書類、🎨オブジェクト・マーク）。
  - 絵文字削除（クリア）ボタン。
  - 下部ツールバーの「😀 絵文字」ボタンからワンタップで起動。
