# MindFlow Studio - ノードつなぎ直し・背景確定・関連線静止＆ラベル強化設計書

## 1. 目的と課題認識

### 1.1 現状の課題
1. **ノードの線のつなぎ直し（親子関係の組み替え）ができない**:
   - 一度作成したノードを別の親ノードへ移動（ドラッグでつなぎ直し）できず、マインドマップの再構成に手間がかかる。
2. **ノード作成時・編集時に背景タップで確定されない**:
   - 新規作成時や編集中、画面背景をタップしても入力が確定されず、ソフトウェアキーボードでEnterを押さないと他の操作ができないため、タブレットやスマホで非常に不便。
3. **関連線の破線アニメーションがチカチカして邪魔**:
   - 破線矢印が常に動くアニメーション（`dash-move`）が視覚的ノイズになり、思考の邪魔になる場合がある。
4. **関連線への文字（ラベル）入力の使い勝手が悪い**:
   - 関連線のラベル編集がPCマウスのダブルクリックを想定したモーダルに依存しており、タップ操作で手軽に文字を入れられない。

## 2. 詳細設計方針

### 2.1 ノードドラッグによる線のつなぎ直し（Re-parenting）
- **ドラッグ判定とドロップターゲット検知**:
  - ノードをドラッグ中、他の可視ノードの中心座標との距離をリアルタイム判定。
  - ルートノードおよび自身・自身の子孫ノードへのつなぎ直しは禁止（循環参照防止）。
  - 有効なドロップ先候補のノードに近づいた場合（近接判定: 距離50px以内または要素領域の重複）、そのノードに `drop-target` スタイル（青いパルス枠線＋「ここへ接続」インジケーター）を付与。
- **ドロップ時の処理**:
  - ドロップ先候補が存在する状態でドラッグ終了（`pointerup`）した場合、元の親の子リストから当該ノードを削除し、新しい親の子リストへ追加。
  - 移動したノードの向き（`direction`）および座標を新しい親に合わせて自動調整。
  - トースト通知（「『○○』の親を『△△』につなぎ直しました」）を表示し、履歴保存（Undo対応）。

### 2.2 背景タップ・他操作時の編集即時確定
- **キャンバス背景タップ時の強制確定**:
  - キャンバス背景（`canvasViewport`）の `pointerdown` / `touchstart` イベント発生時、もし `editingNodeId` が存在すれば、直ちに現在入力中のテキストエリアから値を取得して `finishInlineEdit` を呼び出し確定。
  - `document.activeElement.blur()` を明示的に呼び出し、モバイルOSのソフトウェアキーボードを閉じる。
- **新規ノード作成時のスムーズな確定**:
  - 新規作成されたノードで文字が空または未変更のまま背景タップされた場合でも、安全に確定して編集モードを抜ける。

### 2.3 関連線のアニメーション停止
- **静止した美しい破線への改善**:
  - `dash-move` アニメーションを無効化（静的な `stroke-dasharray: 6, 6` に統一）。
  - 視覚的ノイズを排除し、思考に集中できる落ち着いたデザインにする。

### 2.4 関連線ラベル編集の強化
- **タップで即座に文字入力**:
  - 関連線またはそのラベルバッジを1タップ/クリックしただけで、ラベル編集ポップオーバー（またはクイック入力バー）を表示。
  - よく使われる関係性キーワード（「原因」「影響」「依存」「関連」「参照」「前提」「対立」等）のワンタップ選択ボタンと、自由テキスト入力欄を用意。
  - 関連線を引いた直後にも自動でラベル入力バーを表示し、スムーズに文字を入れられるようにする。
