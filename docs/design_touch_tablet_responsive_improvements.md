# MindFlow Studio - タブレット・スマートフォン対応およびタッチ操作・レスポンシブ設計書

## 1. 目的と課題認識

### 1.1 現状の課題
1. **アイテム（ノード）の移動ができない**:
   - `pointerdown` イベント内で `renderNodes()`（`innerHTML = ''`）を即座に実行しているため、ドラッグを開始しようとしたDOM要素が削除され、ポインターキャプチャおよび以降の `pointermove` / `pointerup` がキャンセルされていた。
   - `touch-action: none` が明示されていないため、iOS Safari / iPadOS や Android においてブラウザのネイティブスクロール/ジェスチャーが優先されてしまう。
2. **縦向き・画面幅縮小時にヘッダーメニューが崩れる**:
   - ヘッダー内の要素（タイトル入力・管理ボタン・入出力・共有・テーマ等）が固定長または多すぎて、画面幅が狭い場合（iPad縦向き 768px、スマートフォン 375px〜430px）にはみ出しや改行が発生する。
   - Undo/Redo および 自動整列ボタンが `hidden lg:flex` となっており、タブレット縦向きやスマートフォンでは Undo/Redo も整列も使えない。
3. **キーボードなしでの操作性が不足している**:
   - ノードのテキスト編集が「PCのダブルクリック」または「F2/Spaceキー」に依存しており、タッチ端末でテキスト編集に入りにくい。
   - ショートカットキー前提の機能（Enter, Tab, Delete, Ctrl+Z/Y）に頼っており、画面上のタッチ操作だけで全機能（子追加、兄弟追加、編集、削除、色変更、メモ、関連線、折りたたみ、チェック、Undo/Redo、整列）が直感的に行えるUIが不足している。
4. **ピンチイン・ピンチアウト（ズーム）および2本指パン操作の未対応**:
   - タブレットやスマホ特有の2本指ジェスチャー（ピンチズーム・パン）に対応していない。

---

## 2. 設計方針

### 2.1 タッチ＆ポインターイベントの根本改修
- **DOM要素の安全なドラッグ**:
  - `pointerdown` 時にはスタイル更新（クラス切り替え）のみ行い、DOMツリーの全再構築（`renderNodes()`）を行わない。
  - `setPointerCapture` を確実に維持し、`pointercancel` ハンドラも適切に定義。
  - `.mind-node` および `#canvasViewport` に `touch-action: none` を適用。
- **マルチタッチジェスチャー（2本指ピンチズーム＆パン）**:
  - タッチイベント（`touchstart`, `touchmove`, `touchend`）または複数ポインタートラッキングにより、2本指タッチ時は指間の距離でピンチズーム、指の中間点の移動でキャンバスパンを実行。
  - 1本指でのキャンバス操作は背景パン、ノード上ではノード移動としてシームレスに機能させる。

### 2.2 ヘッダー・メニューのレスポンシブ刷新
- **ヘッダーレイアウトの階層化**:
  - ロゴとマップタイトルを柔軟な伸縮（`flex-1 min-w-0 truncate`）に対応。
  - Undo/Redo をヘッダー右側または専用のフローティングバーとして、すべての端末サイズで常時アクセス可能にする。
  - スマートフォン・タブレット縦向き向けに、機能群（整列モード、マップ管理、入出力、URL共有、ヘルプ等）を美しくまとめた「モバイルメニュー（ドロワー / ドロップダウン）」を新設。
  - はみ出しや改行が発生しない完全レスポンシブなヘッダー構造とする。

### 2.3 キーボードレス（タッチ端末）操作の完全サポート
- **ノード選択時のクイックアクション**:
  - ノードを1タップで選択した際、下部の操作ドックが確実に反応。
  - 下部ドックに **「✏️ 編集」** ボタンを追加し、ノード選択後にタップするだけで即座にテキスト編集を開始可能にする。
  - ノード自体のダブルタップ（300ms以内の連続タップ）でも確実にインライン編集を開始可能にする。
  - ノード編集時にオンスクリーンキーボードが表示されても画面外に隠れないよう、自動でフォーカスノードを画面中心寄りに微調整。
- **すべての機能へのタッチアクセス**:
  - 子追加、兄弟追加、テキスト編集、チェック、色変更、関連線、折りたたみ、メモ、削除、Undo、Redo、自動整列をすべてワンタップで実行可能。
